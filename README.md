# ⭐ Star Battle Puzzle (星陣物語 / 雙星物語)

一款精美、高響應、現代化的 **Star Battle (Two Not Touch / 雙星謎題)** 網頁遊戲，支援電腦與手機跨平台遊玩、多種難度、即時生成/題庫、計時器、多階段智慧提示、輔助標記、音效合成與多主題切換！

🌐 **線上立即遊玩**：[https://sdyy.github.io/star-battle-puzzle/](https://sdyy.github.io/star-battle-puzzle/)

---

## 🎮 遊戲規則 (Star Battle / Two Not Touch)

1. **行與列限制**：每一行 (Row) 與每一列 (Column) 必須恰好放置指定數量的星星 ⭐。
2. **區域限制**：盤面被粗線分割為若干個不同色塊區域 (Regions)，**每個區域**內也必須恰好放置指定數量的星星 ⭐。
3. **不相鄰原則 (Two Not Touch)**：任何兩顆星星**絕不能相鄰**（包括水平、垂直以及**對角線 8 個方向**均不能相互接觸）。
4. **標記叉叉**：確定不能放置星星的格子標記為 ✖。

## ✨ 遊戲特色

- 🎯 **多種難度挑戰**：
  - 🌱 **入門 (6x6 · 1星)**：規則熟悉、快速上手。
  - ⚔️ **中等 (8x8 · 1星)**：經典單星謎題。
  - 🔥 **困難 (10x10 · 2星)**：標準雙星對弈。
  - 👑 **專家 (12x12 · 2星)**：進階邏輯演繹。
  - 🌌 **大師 (14x14 · 3星)**：高難度燒腦挑戰。
  - 📅 **每日挑戰 (Daily Challenge)**：每日全球統一題目的種子挑戰。
  - 🎲 **無限隨機生成**：隨時生成具有唯一解的全新盤面。
- 📱 **電腦與手機極致操作最佳化**：
  - **電腦端**：滑鼠左鍵點擊循環（空 ➔ ⭐ ➔ ✖ ➔ 空）、滑鼠右鍵/長按一秒標叉、鍵盤快捷鍵（方向鍵導航、`Space`/`S` 放星、`X`/`D` 標叉、`Z` 復原、`Y` 重做、`H` 提示）。
  - **手機端**：底部快捷工具欄，支援**滑動拖曳 (Swipe/Drag)** 連續快速劃叉與清除；支援震動觸覺反饋 (Haptics)。
- 💡 **智慧逐步提示系統**：
  - 偵測星星相鄰衝突並高亮警示。
  - 依循邏輯規則（周圍排除、滿額排除、唯一空位強迫放置）逐步給予清晰文字引導與視覺方框提示，並支援一鍵套用。
- ⚙️ **豐富的自訂輔助選項**：
  - 放置星星時自動對周圍 8 格標叉。
  - 行/列/區域滿額時自動補滿叉叉。
  - 實時紅框高亮衝突星星。
- 🎨 **多款精緻主題**：
  - 🌙 極光深色 (預設)
  - ☀️ 晨曦淺色
  - 🌌 星雲紫調
  - 📜 復古手稿
- 🎵 **純原生 Web Audio 音效**：無需額外載入音效檔案，晶亮落星聲、木質劃叉聲與通關勝利旋律。
- 📊 **成績統計與戰績分享**：記錄各難度通關次數與最佳秒數，並支援產生 Emoji 戰績文字一鍵複製分享。

## 🛠️ 技術架構

- **純前端零相依**：純 HTML5 + CSS3 + ES Module JavaScript，載入極速。
- **約束求解器 (Solver)**：基於 MRV (Minimum Remaining Values) 與前向檢驗 (Forward Checking) 的回溯搜尋引擎，用於即時提示計算與唯一解驗證。
- **程式化題目生成器 (Generator)**：支援多源 BFS 區域生長與群同構變換，確保生成的每個謎題皆具備連通區域與嚴格唯一解。
- **自動化部署**：配置 GitHub Actions 工作流程，程式碼推送到 main 分支即自動發布至 GitHub Pages。

## 🚀 本地端運行

本專案為純靜態網頁，無需任何建置步驟：

1. 複製此儲存庫：
   ```bash
   git clone https://github.com/sdyy/star-battle-puzzle.git
   ```
2. 直接使用瀏覽器開啟根目錄下的 `index.html`，或使用任何靜態伺服器：
   ```bash
   npx serve .
   # 或
   python -m http.server 8000
   ```
